# Serviços

Projeto desenvolvido como parte da **Atividade de Expansão — 11/2024**

## 📱 Descrição

**Serviços** é um aplicativo Flutter voltado para a área da saúde pública. Ele exibe pontos de atendimento, como postos de saúde, hospitais e outros estabelecimentos relacionados, fornecendo informações como horários de funcionamento e dados de contato.

O app utiliza o **Google Maps** para a visualização geográfica desses pontos, proporcionando uma navegação mais intuitiva e prática para os usuários.

## 🚀 Funcionalidades

- 📍 Visualização de estabelecimentos de saúde no mapa  
- 🕒 Informações de funcionamento  
- 📞 Contato direto com os estabelecimentos  
- 🔐 Autenticação com Firebase  
- ☁️ Integração com Firestore e Firebase Storage  
- 📡 Notificações com Firebase Messaging  
- 📊 Monitoramento de desempenho com Firebase Performance  
- ⚠️ Relatórios de erro com Firebase Crashlytics  
- 📸 Upload de imagens com Image Picker  
- 🌐 Abertura de links externos com Url Launcher  

## 🛠️ Tecnologias Utilizadas

- **Flutter** (SDK 3.5.3)
- **Firebase**
  - Authentication
  - Cloud Firestore
  - Crashlytics
  - Performance
  - Storage
  - Messaging
- **Google Maps**
- **Image Picker**
- **HTTP**
- **Url Launcher**
- **Animations**
