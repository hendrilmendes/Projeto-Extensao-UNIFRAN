# 🎓 Projeto de Extensão — UNIFRAN

Este repositório contém o códigos-fontes de apps desenvolvidos como parte da **Atividade de Expansão** da Universidade de Franca (UNIFRAN), sob a orientação do grupo Cruzeiro do Sul Educacional.

## 📚 Sobre o Projeto

O projeto foi concebido com o objetivo de aplicar conhecimentos adquiridos durante o curso de graduação em um contexto prático, abordando temas relevantes para a comunidade e promovendo a integração entre teoria e prática.

## 🛠️ Tecnologias Utilizadas

- **Flutter**
- **Dart**

## 🚀 Funcionalidades Implementadas

- Interface amigável e responsiva.
- Funcionalidades específicas relacionadas ao tema do projeto de extensão.
