# 🌱 Sustentabilidade

Um aplicativo desenvolvido com Flutter como parte de uma atividade de extensão com a temática **"Agir Local e Pensar Global"**, alinhado com os Objetivos de Desenvolvimento Sustentável (ODS) 4 e 12 da ONU. O projeto visa conscientizar sobre práticas sustentáveis através de interatividade, como quizzes e uso da câmera para experiências educativas.

## 📱 Sobre o projeto

Este aplicativo tem como objetivo promover a **educação de qualidade** (ODS 4) e incentivar **consumo e produção responsáveis** (ODS 12), trazendo conteúdos interativos para aumentar a conscientização sobre sustentabilidade no dia a dia.

---

## 🚀 Tecnologias Utilizadas

- **Flutter SDK**: ^3.7.2  
- **Dart**
- **Camera**: Permite o uso da câmera do dispositivo para futuras funcionalidades interativas.
- **HTTP**: Para realizar requisições a APIs externas.
- **Cupertino Icons**: Conjunto de ícones estilo iOS.
